# Menu frame credits and numbering

Frame artwork: Pokémon / Nintendo / Creatures / GAME FREAK; BDSP artwork also ILCA. Reference images supplied by Bulbapedia and Bulbagarden Archives. These credits do not imply endorsement. Existing project licenses and credits remain in effect.

Reference gallery: https://bulbapedia.bulbagarden.net/wiki/Options/Frames

TYPE 1: existing user-selected project border. TYPE 2: existing PokeWilds Java textbox frame. TYPE 3 onward follows the supplied page's gallery order, retaining duplicate entries across games. Borders were extracted from gallery screenshots and adapted to nine-patch textures; the game's existing font is retained. The high-resolution BDSP borders are downsampled to the native viewport.
