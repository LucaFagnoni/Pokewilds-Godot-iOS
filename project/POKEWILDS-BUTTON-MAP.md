# PokeWilds Input Map

| Action | Controller | Keyboard | Touch |
|---|---|---|---|
| Move | D-pad / Left Stick | Arrow keys | D-pad |
| Confirm / Interact | A | Z | A |
| Cancel / Back | B | X | B |
| Run (hold) | X | X (hold) | X |
| Start / Menu | Start | Enter | Start |
| Quit / Save prompt | Select / Back | Escape | — |
| Previous menu/material | L1 | A | L1 |
| Field-move radial (hold) | L2 | — | L2 |
| Zoom out (world/map) | L1 | Mouse wheel down | — |
| Zoom in (world/map) | R1 | Mouse wheel up | — |
| Unassigned | R2 | — | — |
| Unassigned | Y | Y remains a keyboard-only build shortcut | Y is inactive |
| Touch-control config | Android system Back | — | Back |

Touch controls remain available throughout the Android menus and gameplay by
default. Desktop Godot/editor runs never display them.

Hold L2, choose with the left stick, and release L2 to use: BUILD, CUT, FLY,
SURF, DIG, RIDE, SMASH, TELEPORT, FLASH, or CHARM. The selected move requires
an eligible Pokemon in the current party.

No button-press toast/prompt is drawn during gameplay.
