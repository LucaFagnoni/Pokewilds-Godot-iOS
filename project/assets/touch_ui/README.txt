Touch overlay vector assets reconstructed from the user-provided controller layout.
Only the artwork on a button is here (A, B, the MOSSE wheel, the LANCIO ball): the
buttons' shapes, rings and fills are drawn in code (scripts/hud_style.gd).
Nintendo layout: X blue/top; Y yellow/left; A green/right; B red/bottom.
White lettering outlines derive from Anton, used under SIL Open Font License 1.1.
Anton source: https://github.com/google/fonts/tree/main/ofl/anton
