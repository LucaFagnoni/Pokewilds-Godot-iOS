# PokeWilds for iPhone

An iPhone port of PokeWilds, remade in Godot, with a Windows dedicated server for co-op.

## Download

- **iPhone:** [Pokewilds-unsigned.ipa](https://github.com/LucaFagnoni/Pokewilds-Godot-iOS/releases/download/ios-latest/Pokewilds-unsigned.ipa). Sign it with Feather (or a similar tool) before installing.
- **Windows server:** [PokeWilds-Server-win64.zip](https://github.com/LucaFagnoni/Pokewilds-Godot-iOS/releases/download/server-latest/PokeWilds-Server-win64.zip). Unzip it and run `start_server.bat`. Setup guide: [README_SERVER.md](README_SERVER.md).

Both links always point to the newest build. To play together, the phone and the server must be the same build: each release page shows the commit it was built from.

## Source code

Based on [Pokewilds-Android](https://github.com/TryTheSauceBoss/Pokewilds-Android). Original source package: [source-v0.9.3](https://github.com/TryTheSauceBoss/Pokewilds-Android/releases/tag/source-v0.9.3).
